Tovek V2.6

Helpers come back, with proof.

Luau pastes small helpers into the code that calls them. V2.6 finds the copies, checks each one against the bytecode’s own line numbers and Luau’s own arithmetic, and writes the calls back: 8,842 in four real games, up from 4,260.

101 instructions

The bytecode remembers its lines.

With line info (-g1), every instruction keeps the source line it came from. The call on line 893 runs instructions from lines 851 and 852: the helper’s own. So V2.6 can count the copies of helpers too small to prove by shape, and rebuilds them only when its matches equal that count.

The smallest copy is one instruction. In SpawnShield, a sample we wrote, Luau folded frames(1) into one number and kept line 11.

100 expression

A number becomes a call again.

V2.5.1
task.wait(0.016666666666666666)
V2.6
task.wait(frames(1))

V2.6 folds frames(1) the way Luau does, gets the same number and writes the call back. A number that is exactly a fraction prints as one: 2 / 3.

64 bits

Bit for bit.

The constant in the bytecode, Luau’s own fold of 1 / 60, and IEEE division agree on all 64 bits: 0x3F91111111111111.

1 bit

One bit is the difference.

One bit lower is 0.016666666666666663. One higher is 0.01666666666666667. Neither would match. V2.6 rebuilds a folded call only when every bit is the same: proven, not guessed.

01

Inlined helpers come back

Luau -O2 pastes small helpers into their callers. V2.6 finds and rebuilds about twice as many of them.

rebuilt helper calls, four real games
4,260→to8,842
rebuilt helper calls, 51-script comparison set
229→to637
inlined copies found from line info that came back as calls (51-script set)
633 of 780
  1. 1.1
    Line evidence

    Luau keeps a helper's own line numbers on the code it inlines. V2.6 reads them to count the copies of each helper in each function, and rebuilds helpers too small to prove by shape alone, such as if c then c:Disconnect() end, when the matches it finds equal that count exactly.

    DisconnectEvent in Roblox's ClickToMoveController: 12 copies in the bytecode, 12 calls rebuilt.

  2. 1.2
    Folded constants solved back

    When Luau folds a copy of a pure helper into one number, V2.6 redoes Luau's constant folding bit for bit and writes the call back: task.wait(0.016666666666666666) becomes task.wait(frames(1)). Constant arguments folded into a larger copy are solved from equations, such as fade(part, 0.5).

    task.wait(0.016666666666666666) becomes task.wait(frames(1))

  3. 1.3
    More copy shapes

    Copies whose result is assigned to an existing local, stored into a field or thrown away; helpers that return from both branches or return several values (local width, height = measure(frame)); copies specialized for a constant; unnamed functions that are only ever called; helpers also stored under their own name; and value copies after any number of statements.

  4. 1.4
    The larger copy wins

    Where two helpers match the same code, the one that stands for more of it is rebuilt instead of neither.

  5. 1.5
    Exact counts in the output

    Every line holding a rebuilt call ends with -- inferred equivalent call, and each helper's definition line states how many calls were rebuilt from it.

02

Exact where it was not

A new fuzzer checks random programs against their own bytecode. Every bug it and the code reviews found is fixed at its cause.

wrong outputs in 3,000 fresh fuzz programs
615→to0
scripts decompiled, four real games
8,822 of 8,822
  1. 2.1
    Closures keep their identity

    Two functions stay the same object only where the original made them the same object. A loop that made a new function each time no longer prints code that shares one (DUPCLOSURE against NEWCLOSURE).

    original prints false; V2.5.1's output prints true; V2.6's prints false

  2. 2.2
    Captured values stay captured

    A closure always sees the value it captured, also where a local is copied, swapped or written later. One such case made a popular Promise library recurse forever.

  3. 2.3
    Error positions and call frames

    A helper that reports an error at its caller's position (error(message, 2), debug.info) is not rebuilt, because the position would move. A method that only reads its own frame no longer turns rebuilding off for its whole script.

  4. 2.4
    Evaluation order

    Luau reads a local's register when the operation runs, after the other operands. Rebuilt calls, snapshots and stores now keep that order (x + change(), t[saved] = change()).

  5. 2.5
    Your handles stay

    local Lighting = game:GetService("Lighting") and require handles stay declared; a rebuilt call never swallows them.

  6. 2.6
    Big functions compile

    Output that would need more registers or locals than Luau allows shares storage until it compiles, including -g2 code with hundreds of do local a = ... end blocks.

  7. 2.7
    Loops and tables

    Loops that only break after a swap, for _ in t do break end, a swap right before a generic for, and [0] beside [-0] table keys all decompile to code that behaves like the original.

03

Reads more like the source

Shorter, tidier output with names closer to what people write.

non-blank output lines, four real games
1,168,956→to1,033,044
output lines, 51-script set
28,813→to26,664
source names recovered, 13 public modules
282→to317 of 1,039
  1. 3.1
    Exact fractions

    A number that is exactly p / q prints as that fraction when it is bit-equal and shorter, over the denominator the source most likely used: 2 / 3, 190 / 255, frames over 60.

    clone.Transparency = 0.6666666666666666 becomes clone.Transparency = 2 / 3

  2. 3.2
    Layout

    Short tables on one line, call arguments within a width budget, long conditions wrapped, one multi-line list element per line, --!native and @native restored, and a comparison inside a comparison in parentheses.

  3. 3.3
    Names

    Acronyms as one word, a private _ prefix dropped, the source's own spelling for aliases and unused imports, xpcall named like pcall, nested loop counters i, j, k, suffixes the source wrote, such as Part_2, kept, and a recursive call no longer blocks the name another caller gives a parameter.

04

Tools

One new flag and faster formatting.

  1. 4.1
    --stats-json

    decompile-folder --stats-json <file> writes, per script, the calls V2.6 rebuilt (by kind), the helpers, and why a helper or a site was refused.

  2. 4.2
    Faster formatting

    Repeated formatter work is gone and cached batches run in parallel. A pathological script of twenty nested string formats went from 7.6 s to 0.15 s.

Typed random Luau programs, 1,000 seeds at -O0, -O1 and -O2, half of them with patched bytecode, each decompiled, compiled again and run beside its own bytecode. Refused: the decompiler declined (only expected on patched bytecode). Invalid: the generated program itself does not compile (e.g. register limit). Where V2.6 leads: rebuilt calls, fewer generated names, source names. Of the inlined copies of named helpers that line info shows, 633 of 780 came back as calls (81%).
