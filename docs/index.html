Luau decompiler · V2 v0.1 · bytecode v4–v13

Give bytecode its names back.

Tovek turns stripped Roblox bytecode into Luau you can actually read. It infers identifiers from how values are used, rebuilds the helpers and UI trees the -O2 optimizer flattened, and checks every result against Luau's own compiler and VM. No v1, v2, v3.

01

Fig. 01 · de-inliner

The optimizer erased the helper. Tovek rebuilt the call.

Luau -O2 inlines small functions at every call site, so the shipped bytecode contains no CALL to them at all. Tovek keeps the helper, matches its body against the expanded code and restores the call — only when body, arguments, captures and result arity line up exactly.

1 the author wrote
Zone.server.luasource
local function isNear(a, b, range)
	return (a.Position - b.Position).Magnitude <= range
end

-- …
if root and isNear(root, zone, range) then
2 the compiler shipped
luau-compile --text -O2bytecode

Zone.server.luaureconstructed
--  equivalent calls inferred from this helper; original call sites unknown
local function isNear(p, p2, p3)
	return (p.Position - p2.Position).Magnitude <= p3
end

-- …
if not (humanoidRootPart and isNear(humanoidRootPart, zone, p)) then

The rebuilt helper carries that comment on purpose: a matching body proves the call is equivalent, not that the author wrote it there. A pure-arithmetic helper in the same file, scaled(value, factor), stays expanded because the proof didn't go through. Tovek never guesses.

02

Fig. 02 · name inference

Every name has a reason.

Roblox strips local names before a script reaches the client. Tovek doesn't recover them — nothing can — it infers them from evidence: which method produced a value, which field it was stored to, which event slot it fills. Hover a name to see its evidence. Flip the switch to see what the bytecode actually records.

03

Fig. 03 · ui reconstruction

Scattered writes. One declarative tree.

At -O2 a React or Fusion element becomes table allocations, field stores, a computed event key and a callback, spread across registers. Tovek folds them back — leaves first — into the nested constructor the author wrote, while keeping every observable operation in its original order.

Button.luaureconstructed · -O2 -g1
local react = require(script.Parent.Parent.React)
local createElement = react.createElement

local function Button(p)
	return createElement("TextButton", {
		Text = p.text,
		Size = UDim2.fromOffset(160, 44),
		BackgroundColor3 = Color3.fromRGB(30, 30, 30),
		[react.Event.Activated] = p.onClick
	}, {
		Corner = createElement("UICorner", {
			CornerRadius = UDim.new(0, 8)
		}),
		Stroke = createElement("UIStroke", {
			Thickness = 1,
			Color = Color3.fromRGB(80, 80, 80)
		})
	})
end

return Button
element tree · hover

Computed event keys such as [react.Event.Activated] and drained children tables are rebuilt too. A table only absorbs initialization that no other code could have observed in between — anything already visible stays where it was.

04

Fig. 04 · methods & types

Colons and types, back where they were.

Method tables written with an explicit self come back as function T:method(). Bytecode compiled with type information keeps its parameter tags, and Tovek writes them back as annotations — never inventing a spelling the bytecode doesn't hold.

OOP recovery

Inventory.luau-O2 -g1
function class:Add(p)
	if self.count >= self.capacity then
		return false
	end

	local items = self.items
	table.insert(items, p)
	self:Refresh()
	return true
end

function class:Refresh()
	self.count = #self.items
	self.owner:SetAttribute("ItemCount", self.count)
end

self is recognised from how the first parameter is used — method calls, field writes, the setmetatable constructor — not from a name the bytecode no longer has. A method that only reads fields stays in dot form rather than being guessed.

Type annotations

Module.luau-O2 -g1 -t1
scale = function(p: number, value: number?, p2: string)
	local v2 = p * (value or 1)
	return p2 .. "=" .. tostring(v2)
end,
configure = function(p, flag: boolean, callback, list, vector: Vector3, buf: buffer)
	if flag then
		callback(#list)
	end

	return p, vector, buf
end

table, function and untagged userdata stay unannotated: the bytecode doesn't keep their spelling. Recompiling the output reproduces the same type tags — and the tags double as a last-resort naming hint (vector, buf, flag, callback).

05

Fig. 05 · control flow

Loops you would have written.

V2's structurer rebuilds source-like loops from explicit ownership, edge-transfer and iterator-protocol checks: continue guards, early returns, repeat … until, shared tails emitted once. Underneath, evaluation order, closure identity and result counts are protected — when a rewrite can't be justified, Tovek keeps the snapshot.

Module.luau-O2 -g1
function Module.collect(list, p, p2)
	local parts = {}

	for _, part in ipairs(list) do
		if not part:IsA("BasePart") or p2 < (part.Position - p).Magnitude then
			continue
		end

		parts[#parts + 1] = part
	end

	return parts
end

function Module.countdown(p)
	local v = p

	repeat
		task.wait(1)
		p -= 1
		print("T-" .. p)
	until p <= 0

	return string.format("%d seconds elapsed", v)
end

Engine sheet

Built for whole games, not single files.

A Rust CLI that eats a SaveInstance dump in parallel, a local HTTP server for the executor workflow, and a batch API — all producing byte-identical output no matter how many threads you throw at it.

Straight talk

What Tovek won't pretend.

Bytecode does not uniquely determine source. The point of V2 is to make the remaining evidence as useful as possible — and to be explicit about where evidence ends.

  • —Names are inferred, not recovered. The author's identifiers, comments and erased types are gone from the bytecode. Tovek reports evidence-based names and labels reconstructed calls as inferred.
  • —Runtime-mutated CMPPROTO guards are reported with their prototype and instruction location instead of rendered as a guessed condition.
  • —v14 bytecode is not supported yet. Malformed or truncated v12 input is rejected rather than decoded on a best-effort basis.
  • —Recompiling is not equivalence. Fixtures are executed and compared, which proves the tested inputs — not every program.
  • —Some math-heavy code still carries extra intermediates compared with the original. The release article lists every measured regression alongside the gains.
