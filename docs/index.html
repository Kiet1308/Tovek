Every instruction remembers its line.

Luau -O2 pastes small helpers into their callers and folds calls into bare numbers. Each pasted instruction still carries the helper’s line number. Tovek, a free decompiler for Roblox bytecode, uses it to write the call back.

One call, proven to the bit.

In a callback inside Beacon.start, the bytecode holds a bare number where the source called a helper. Until V2.6, every release printed that number. This is each step Tovek V2.7 takes before it writes the call back.

  1. The instruction loads a constant. Its line-table entry says line 16.

    16LOADKR5 K20 [0.016666666666666666]

  2. Line 16 is not in this function. It is the body of frames, which divides its argument by 60.

    16DIVKR1 R0 K0 [60]16RETURNR1 1

  3. Tovek solves that body for the argument.

    p / 60 = 0.016666666666666666p = 1

  4. It divides 1 by 60 the way Luau folds constants, and compares the result with the constant in the file, bit by bit.

    in the bytecode0x3F91111111111111

    1 / 60, folded0x3F91111111111111

    sign and exponent, 2−6mantissa, 52 bits64 of 64 bits agree

  5. Only now is the call written, and marked as inferred.

    task.wait(frames(1)) -- inferred equivalent call

The mark means a call that behaves the same. It makes no claim about where the source called the helper. Where a file has no line info, or any check fails, the number stays a number.
