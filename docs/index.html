Roblox bytecode, read back into source.

Tovek turns compiled Luau scripts back into code you can read: names from evidence, loops instead of jumps, and the helper calls the compiler pasted away. It runs on your machine, free and open source.

    I

    What Tovek is

    It is

    • A decompiler for Luau, the language of Roblox. It reads the bytecode Roblox ships and the bytecode luau-compile writes.
    • Deterministic. The same bytes give the same output, every time, on every machine.
    • Local. A command-line tool and a small HTTP server that run on your own computer.
    • Free and open source, under the MIT licence.

    It is not

    • A guesser. Where the bytecode gives no evidence for a name, Tovek keeps a plain one.
    • A way to get back what compiling removes: comments, formatting, and the original names of locals and constants.
    • A cloud service. Nothing you decompile leaves your machine, on this page or anywhere else.

    II

    How we know it is right

    0

    wrong outputs in 3,000 fresh programs

    A fuzzer writes typed random programs, compiles each at -O0, -O1 and -O2, and runs Tovek’s output beside the bytecode on the same VM. 2,582 matched; 286 patched inputs were refused rather than guessed; none came out wrong.

    648/648

    edge-case runs pass

    Every reported or fuzzed bug stays as a test: 216 small programs, compiled at three optimization levels, decompiled, compiled again and run beside the original.

    8,822/8,822

    scripts in 4 real games decompile

    8,842 inlined helper calls written back (V2.5.1: 4,260), and 11.6% fewer lines for the same behaviour. The games stay unnamed.

    These checks cover the programs tested. Bytecode does not pin down one source, so Tovek writes code that behaves the same, not code that is guaranteed to be identical. How V2.6 was measured

    Each download holds two programs, luau-lifter and web-server, and the licence. All files and checksums

    On the command line

    • luau-lifter script.luacone file of raw Luau bytecode
    • luau-lifter script.lua -e --script-name Workspace.ScriptRoblox client bytecode
    • luau-lifter decompile-folder ./dump ./outa whole saved game, every core at once
    • luau-lifter validate-folder ./dump ./outthe same, then every output through Luau’s own parser

    As a local server

    • web-serverlistens on http://127.0.0.1:3000
    • POST /decompileone script, base64 bytecode in the body
    • POST /decompile/rawone script, raw bytecode
    • POST /decompile/batchmany scripts in one request
