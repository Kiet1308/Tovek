The bytecode remembers its lines

Luau folded frames(45) into the number 0.75. That 0.75 still carries line 16, the return inside frames, so Tovek writes the call back after checking that 45 / 60 is exactly 0.75. medal and every release before V2.6 printed TweenInfo.new(0.75).
