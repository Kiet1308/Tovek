Tovek V2.1.1
https://github.com/Kiet1308/Tovek

This package contains the local Luau decompiler CLI and HTTP server.
AI is disabled. No model, network service or account is required to decompile.

CLI (Windows: use .\luau-lifter.exe; Linux: use ./luau-lifter)
  luau-lifter script.luac > script.luau
  luau-lifter script.luac -e > script.luau
  luau-lifter decompile-folder ./dump ./output

Use -e for raw Roblox client bytecode (encoding key 203). Folder mode reads
saved-bytecode text files and defaults to that key. Use --key 1 in folder mode
for unencoded bytecode. --help describes the remaining options.

HTTP SERVER
Start web-server.exe (Windows) or ./web-server (Linux).
The server listens locally at http://127.0.0.1:3000.
POST /decompile accepts base64 bytecode; /decompile/raw accepts raw bytes.
The included decompile.client.luau and decompile-batch.client.luau connect an
executor to the local server. See README.md for usage and endpoint formats.
Up to four decompile requests run at once; later requests wait in a queue
(TOVEK_QUEUE_LIMIT, default 1024 waiting; TOVEK_QUEUE_TIMEOUT_SECS, default 120).
A full queue or an expired wait answers 503 with Retry-After, which the included
client scripts retry. An upload must finish within 30 seconds once it is
admitted (408 otherwise); set TOVEK_UPLOAD_TIMEOUT_SECS to change it.

COMPATIBILITY
Windows x86_64, or Linux x86_64 with glibc 2.35 or newer (Ubuntu 22.04+).
Luau bytecode v4-v14 is supported, including Roblox v12 (CALLFB, wide cost
metadata) and the v14 FASTPCALL fast path for pcall/xpcall.
Malformed or truncated bytecode is rejected with the prototype and instruction
at fault. v15+ and runtime-mutated CMPPROTO guards are rejected.
Decompilation cannot recover stripped comments or guarantee original names.
