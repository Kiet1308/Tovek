Tovek V2.7 gives back more of what the Luau compiler took away, and decompiles
every edge case we have found exactly.

De-inlining
- Copies Luau pasted into their callers come back as calls in more places:
  helpers whose early return from a loop became a store and a break, copies
  whose constants Luau folded through branches, locals and math.pow, copies
  inside other copies, copies split by a declaration the caller evaluated in
  between, and calls that forward their varargs.
- Every rebuilt call is checked twice: the helper, specialized to the call's
  constant arguments, must match the copy exactly, and evaluating the arguments
  first must change nothing the copy observed. Where the bytecode's line
  numbers show none of a helper's code in a function, a match there is code the
  author wrote, and it stays as written.
- Four real games (9,987 scripts): 8,474 -> 9,623 rebuilt helper calls.

Exactness
- 341 edge-case fixtures at -O0, -O1 and -O2: 1,023 of 1,023
  runs decompile, recompile and print what the original prints (V2.6.1: 965).
- 658 review cases: 0 decompiled wrong (V2.6.1: 93).
- 9,000 fresh typed fuzz programs: no wrong output. Hand-patched bytecode no
  source can spell is refused, never printed as something else.
- Table constructors keep their bytecode's allocation, so pairs visits keys in
  the same order, including explicit array keys beside record keys.

Names and presentation
- Names from evidence for rebuilt calls, running extremes, sets, collection
  elements, stored clock readings and documented Roblox APIs. Four games:
  generated names 60,491 -> 58,668; output 1.5% shorter.
- Guard clauses, bottom-tested loops and one-shot loops read as written; do
  blocks keep their scope; Roblox vector constants print as Vector3.new.

Scale
- Long functions no longer grow passes quadratically, and the HTTP server
  streams large batches and returns memory when idle. Decompile time on the
  four games is about the same as V2.6.1.

Downloads: Windows x86_64, Linux x86_64, Linux aarch64 and macOS (Apple silicon).
Each package contains luau-lifter (CLI), web-server (local HTTP server), and the
MIT licence. SHA256SUMS.txt lists the checksums.
